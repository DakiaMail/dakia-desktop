## Native acceptance still required

The b14 native results above establish named attachment, shared-profile and forward-upgrade observations. The following aggregate requirements remain open for completed native acceptance:

- Production provider/watch supervisor through Tauri events to Reader across the remaining representative corpus and restart boundaries. The historical 04b checkpoint exercised UID 5 publication and external star/unstar convergence.
- Broader MIME corpus and repeated Reader behavior. The c2 slice rejected four exact malformed graph seeds while preserving a valid neighbor, but it does not establish every mixed/alternative or generated-Message-ID case.
- Remaining attachment interruption and cancellation cases. The b14 native slice adds real individual and Save All truncated-literal failures, empty Downloads assertions, exact-byte retries, 0600 mode, quarantine and unsafe-warning evidence. A user cancellation API is absent, so user-driven cancellation cannot be claimed tested.
- Submitted-with-Sent-copy-failure recovery beyond the bounded c2 case. C2 kept one terminal recovery view-only with Send disabled through a same-profile relaunch, but it did not capture a recipient-mailbox watermark proving absence of every automatic resend. A retryable not-submitted user retry is separate.
- UID7 leap-second display, keyboard/focus/privacy/notification workflows and native foreground responsiveness.
- Same-profile restart beyond the bounded c2 terminal case and b14's eight concurrent read-only CLI operations. Neither slice establishes broader restart, UID 7, downgrade or release acceptance. Downgrade remains unsupported and requires complete backup/restore; published v0.4.4 does not enforce the new marker.

Prepared helper tests and independent reviews do not count as these native passes.
