# Security Policy

## Supported versions

Security fixes are made on the latest release and the `main` branch. Older
releases may not receive patches.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/DakiaMail/dakia-desktop/security/advisories/new).
If that is unavailable, email [support@dakiamail.com](mailto:support@dakiamail.com).

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not include mailbox contents, passwords, tokens, private keys, or
other people's personal data. We will acknowledge a report within seven days
and coordinate disclosure after a fix is available.

## Scope

Reports about Dakia's desktop application, CLI, website, release artifacts, and
update mechanism are in scope. Provider availability, provider-side behavior,
and social engineering without a product vulnerability are out of scope.
